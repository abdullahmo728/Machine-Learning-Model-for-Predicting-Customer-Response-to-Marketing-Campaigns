This project aims to analyze customer data and build a machine learning model capable of predicting the likelihood of customer response to marketing campaigns, helping companies target the most responsive customers, improve campaign efficiency, and reduce costs.

A marketing campaign dataset was used, containing demographic and behavioral information such as age, income, marital status, previous purchase frequency, and customer interaction with marketing offers. The project included the following steps:

-Data cleaning and preprocessing to handle missing and inconsistent values
-Converting categorical variables into numerical values using appropriate encoding techniques
-Applying scaling techniques to improve model performance
-Performing exploratory data analysis (EDA) to understand customer behavior patterns and key influencing factors
-Splitting the data into training and testing sets to ensure fair evaluation

Multiple classification algorithms were applied to build the model, and performance was evaluated using metrics such as Accuracy, Precision, Recall, and F1-score to select the best-performing model.
